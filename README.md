# CODSOFT Java Development Internship

## About
This repository contains the Java programming tasks completed as part of my virtual Java Development Internship at CodSoft.

The projects helped me practise Java programming fundamentals, problem-solving, input validation, and Object-Oriented Programming (OOP).

## Tasks Completed

### Task 1: Number Guessing Game
A console-based game in which the user guesses a randomly generated number between 1 and 100.

**Features:**
- Random number generation
- Limited attempts per round
- Feedback for guesses that are too high or too low
- Input validation
- Multiple rounds and score tracking

**Technology:** Java

### Task 2: Student Grade Calculator
A Java application that calculates a student's total marks, average percentage, grade, and result based on marks entered for each subject.

**Features:**
- Input marks for multiple subjects
- Marks validation
- Total marks calculation
- Average percentage calculation
- Grade assignment and pass/fail result

**Technology:** Java

### Task 3: ATM Interface
A console-based ATM simulation that allows users to perform basic banking operations.

**Features:**
- Check account balance
- Deposit money
- Withdraw money
- Validate transaction amounts
- Handle insufficient balance
- Menu-driven interface

**Technology:** Java, Object-Oriented Programming (OOP)

## How to Run
1. Clone or download this repository.
2. Open the project or source files in IntelliJ IDEA.
3. Configure a compatible JDK.
4. Run the main class for the task you want to execute:
   - `NumberGame.java`
   - `GradeCalculator.java`
   - `ATM.java`

For Task 3, keep `ATM.java` and `BankAccount.java` in the same package.
